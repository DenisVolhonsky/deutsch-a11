Deutsch A1 — локальная исправленная версия v6.1

Проверка:
1. Распаковать архив.
2. В папке приложения: python3 -m http.server 8081
3. Открыть http://localhost:8081/

Важно: новый порт 8081 изолирует предварительный просмотр от старого Service Worker на 8080. На localhost регистрация Service Worker отключена. На HTTPS он остаётся для офлайн-работы.

Данные словаря и функциональность пока те же, что в v6. Публикация на GitHub не выполнялась.
